# Север и Степь

Текстовая браузерная RPG в духе классических WAP-игр (Barbars и подобных): интерфейс из ссылок,
две враждующие фракции, бои по кликам, прокачка и война за башни. Работает целиком в браузере,
прогресс сохраняется в `localStorage`.

## Как запустить

Откройте `index.html` в браузере — сборка и сервер не нужны.
Или `npm start` и перейдите на http://localhost:8000. Подходит и для GitHub Pages.

## Что есть в игре

- **Фракции:** Северяне (Хольмгард) и Степняки (Кара-Тау).
- **Мир:** столица и 5 локаций по уровням — Тёмный лес, Гнилые топи, Древние руины, Ледяные горы, Выжженные пустоши.
- **Бой:** атака, мощный удар и лечение за энергию, зелья, побег. Криты, промахи, броня снижает урон.
- **Развитие:** опыт и уровни (3 очка параметров за уровень), тренер — Сила, Живучесть, Энергия, Броня
  за очки или золото.
- **Снаряжение:** 6 слотов, 5 качеств (обычное → легендарное), заточка в кузнице до +10 с риском неудачи.
- **Город:** лавка, тренировочный двор, кузница, таверна с заданиями, арена против бойцов вражеской фракции (слава).
- **Башни:** 4 башни, их можно штурмовать. Каждая своя башня даёт +5% опыта и золота; враги отбивают их со временем.
- **Подземелья:** Склеп Забытого Короля и Чёрная цитадель — цепочка боёв без регенерации, в конце босс с гарантированной редкой добычей.
- Регенерация здоровья и энергии в реальном времени, журнал событий, перенос сохранения через код.

## Структура

```
index.html        — страница
css/style.css     — оформление (мобильный WAP-стиль)
js/data.js        — данные: локации, монстры, предметы, задания
js/game.js        — игровая логика без DOM (тестируется в Node)
js/ui.js          — экраны и обработка кликов
tests/            — юнит-тесты и симуляция баланса
```

## Разработка

```
npm test          # юнит-тесты (node:test)
npm run balance   # бот проходит игру и выводит темп прокачки
```

## Идеи для развития

Сервер и настоящий мультиплеер (Node.js + WebSocket/БД), чат, кланы, рынок между игроками,
групповые бои за башни, рейтинги, ежедневные награды.
